# Machine Learning Repository

## Overview
This repository serves as a structured collection of code, datasets, and Jupyter Notebooks developed while studying *Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow* by Aurélien Géron. It documents practical implementations of foundational machine learning algorithms, data processing pipelines, and model evaluation techniques.

## Repository Structure

The files in this repository correspond to key machine learning concepts and end-to-end project implementations:

*   **`Datasets/`**: Contains the local data files and resources utilized across various notebooks for training and testing models.
*   **`End to end .ipynb`**: A comprehensive walkthrough of an end-to-end machine learning project. This notebook covers data fetching, exploratory data analysis (EDA), data preparation, model selection, and fine-tuning using the California housing dataset.
*   **`ML_HOUSING.py`**: Modularized Python scripts and custom transformers supporting the housing project, demonstrating software engineering best practices within machine learning workflows.
*   **`classification.ipynb`**: An in-depth exploration of classification algorithms. This includes implementations of binary and multiclass classifiers, alongside thorough performance evaluations using metrics such as Precision, Recall, F1 Score, and ROC/AUC curves.
*   **`Training Models.ipynb`**: A technical deep dive into the underlying mechanics of model training. It covers the mathematical and programmatic foundations of Linear Regression, various Gradient Descent optimization algorithms, and Polynomial Regression.

## Technology Stack

The projects and exercises within this repository utilize the following technologies and libraries:
*   **Language:** Python
*   **Environment:** Jupyter Notebook
*   **Core ML Framework:** Scikit-Learn
*   **Data Manipulation & Analysis:** Pandas, NumPy
*   **Data Visualization:** Matplotlib, Seaborn
